# Обработка

Исходные JPEG сохраняют цвета, тени, фактуру и обводку. Сборка удаляет внешний фон и экспортирует PNG для Telegram.

1. Исходный ICC-профиль, если присутствует, переводится в sRGB. У предоставленных JPEG профиля нет, поэтому RGB интерпретируется как sRGB. Экспорт содержит явную метку PNG sRGB.
2. Светлая внешняя область выделяется заливкой от границ холста. Замкнутый контур защищает белое полотнище. Выбирается крупнейшая компонента; внутренние области сохраняются непрозрачными. Вырезы Alfa и Bravo остаются прозрачными.
3. Альфа сглаживается в узкой полосе по краю. Цвета полупрозрачной кромки берутся с ближайшего участка исходного контура, чтобы убрать белый ореол JPEG. RGB всех полностью непрозрачных пикселей сохраняется точно после приведения к sRGB. RGB полностью прозрачных пикселей обнуляется.
4. Версия в `processed/` сохраняет исходный холст 1024 × 1024 или 2048 × 2048. Для `emoji/` прозрачные поля обрезаются, изображение пропорционально вписывается в 90 × 90 и центрируется на холсте 100 × 100. Уменьшение выполняется Lanczos с premultiplied alpha; крайние слабые пиксели ringing удаляются. При нечётном отступе допустима асимметрия 1 px.

Метод рассчитан на замкнутый контур и светлый внешний фон. Для новых изображений нужно проверить маску и при необходимости настроить `background_threshold` в `scripts/flags.json`. Ширина сглаживания масштабируется относительно исходной стороны 1024 px.

Проверки в `scripts/build.py` контролируют состав исходников, SHA-256, PNG/RGBA/sRGB, размеры, прозрачные границы, непрозрачное ядро, связность силуэта, отсутствие отверстий, размер объекта и поля эмодзи. Дополнительно сохранённый PNG высокого разрешения сравнивается с исходником по RGB каждого полностью непрозрачного пикселя. Результаты записываются в `docs/validation.json`.
