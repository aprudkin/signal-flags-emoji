# Статичный набор эмодзи в Telegram

Готовый набор: [Добавить эмодзи в Telegram — HoistTheFlags](https://t.me/addemoji/HoistTheFlags).

Готовые изображения находятся в `emoji/`: 26 PNG RGBA, строго 100 × 100 px, с прозрачным фоном. Telegram допускает PNG или WEBP именно такого размера для статичных пользовательских эмодзи; обычные стикеры имеют другие требования. [Официальные требования](https://core.telegram.org/stickers#static-stickers-and-emoji).

1. Откройте официальный бот [@Stickers](https://t.me/Stickers), нажмите **Start / Запустить**. У бота есть мини-приложение и текстовые команды; для последовательности ниже используйте чат с ботом.
2. Отправьте `/newemojipack`. Выберите **Static emoji / Статичные эмодзи** из предложенных вариантов. Если меню изменилось, отправьте `/help` и выберите создание набора статичных эмодзи.
3. Введите название, например **Морские сигнальные флаги**. Не включайте `/adaptive`: набор цветной, его цвета должны сохраняться.
4. Прикрепите первый PNG из `emoji/` **как файл / документ**, а не фотографию. На компьютере при перетаскивании выберите отправку без сжатия; на телефоне — «Скрепка → Файл». Не используйте изображения из `previews/` или `originals/`.
5. В ответ на запрос бота отправьте обычный Unicode-эмодзи для привязки, например 🚩 или ⛵. Можно использовать один и тот же обычный эмодзи для нескольких флагов. Это поисковая ассоциация, а не обозначение морского сигнала; произвольную букву вместо эмодзи бот может не принять.
6. После подтверждения добавления загрузите следующий PNG и снова отправьте обычный эмодзи. Повторите для всех нужных файлов. Каталог `CATALOG.md` помогает сверять названия; у некоторых исходников есть отмеченные отклонения от стандартного рисунка.
7. Отправьте `/publish`. Следуйте дополнительным запросам бота. Если он предлагает необязательную обложку и разрешает пропустить её, используйте `/skip`.
8. Укажите свободное короткое имя для ссылки, например `signal_flags_aprudkin`. Если имя занято, выберите другой вариант. Точный допустимый формат подскажет бот.
9. Бот вернёт ссылку вида `https://t.me/addemoji/<short_name>`. Откройте её, добавьте набор и проверьте несколько флагов рядом с текстом в «Избранном» на светлой и тёмной темах.

Названия кнопок могут отличаться по языку и версии приложения; при расхождениях следуйте текущим подсказкам официального бота. [Telegram подтверждает](https://core.telegram.org/stickers#stickers-mini-app), что функции @Stickers доступны также текстовыми командами.

По [текущему описанию Telegram](https://core.telegram.org/stickers#custom-emoji) создавать пользовательские эмодзи могут все, а добавление и использование собственных наборов относится к Telegram Premium. Условия сервиса могут меняться. Инструкция сверена с официальной документацией 8 ноября 2026 года.
